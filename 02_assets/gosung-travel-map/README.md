# 우리 숙소 주변 여행하기 — 지도 섹션

숙소 홈페이지 안에 넣는 「주변 여행지도」 섹션 하나. 단독으로 열어도 동작하는 프로토타입.

## 파일

```
gosung-travel-map/
├─ index.html      ← 화면·동작·스타일 (이 한 파일이 섹션)
├─ basemap.js      ← 지도 레이어 (배경 이미지 + 지명 라벨). 지도만 갈아끼울 수 있게 분리
├─ places.js       ← 장소 데이터 (여기만 고치면 내용이 바뀜)
├─ 좌표찍기.html    ← 핀 위치 잡는 도구 (배포할 때는 빼도 됩니다)
├─ fonts/          ← Pretendard woff2 3종 (외부 요청 없이 쓰려고 같이 넣음)
└─ images/
   ├─ map-goseong.jpg   ← 지도 배경 (1448 x 1086)
   └─ (관광지 사진 10장, 3:2 기준 contain 표시)
```

`index.html` 을 더블클릭하면 바로 열립니다. (`basemap.js` · `places.js` 는
`<script src>` 로 불러오므로 로컬 서버 없이도 열립니다.)

## 지금 들어있는 것

### 지도

`images/map-goseong.jpg` **한 장을 깔고 그 위에 지명만 SVG 텍스트로 얹는 구조**입니다.
지도 API·계정·요금 없습니다.

- 배경 이미지는 생성형 AI 로 만들었고, **실제 고성군 지형을 참고로 넣어 만들어서
  해안선·섬·산의 위치가 실제와 거의 맞습니다.** (핀 위치가 의미를 가지려면 이게 중요)
- 지명(면 이름 · 이웃 시 · 진해만)은 SVG 텍스트라 언제든 고칠 수 있습니다 → `basemap.js`
  (당항만 · 고성만 · 한려해상은 지웠습니다. 모바일에서는 면 이름이 자동으로 숨겨집니다)
- 이전에 직접 그렸던 일러스트 SVG 지도는 `../지도참고/basemap-일러스트버전.js.bak` 에 보관돼 있습니다.
  파일 이름을 `basemap.js` 로 바꿔 덮어쓰고, 아래 「지도를 바꾸고 싶을 때」의 비율만 4:3 으로
  되돌리면 그 지도로 복구됩니다.

### 동작

- 관광지 핀 9개 + 숙소 핀 1개
- 핀 hover → 말풍선 라벨 / 클릭 → 오른쪽 카드 교체
- 숙소 → 선택한 장소까지 주황 점선 연결
- 드래그 이동 · 휠/버튼 확대(최대 3.2배) · `전체 보기`로 복귀
  (기본은 지도 전체가 한 화면에 들어온 상태, 확대했을 때만 선택한 핀이 가운데로 이동)
- 오른쪽 카드: 사진(3:2) / 장소명 / 차로 약 ○분 / 한 줄 소개 / 외부 링크(새 탭)
- 거류산은 사진 2장 → 카드 사진 아래 점으로 전환
- 모바일: 지도 위 + 아래 카드 좌우 스와이프, 카드를 넘기면 지도도 따라감

## 고치는 법

### 장소 내용
`places.js` 만 고치면 됩니다.

```js
{
  id: "galmobong",
  name: "갈모봉자연휴양림",
  x: 39.6, y: 60.4,         // 지도 위 위치 (왼쪽위 0,0 ~ 오른쪽아래 100,100 기준 %)
  driveMin: 10, driveKm: "5km",
  summary: "숙소에서 가장 가까운 편백 숲길, 아침 산책으로 딱 좋아요",
  hours: "", parking: "", fee: "",   // 값을 채우면 카드에 줄이 생김 (지금은 비움)
  linkLabel: "네이버 지도에서 보기",
  linkUrl: "https://naver.me/...",
  photos: [{ src: "images/갈모봉자연휴양림.jpg", credit: "ⓒ한국관광공사", license: "제3유형" }]
}
```

- 카드 순서 = 배열 순서 = 핀 번호. 지금은 **고성 관광안내도의 9경 순서**입니다.
  (① 당항포 ② 상족암 ③ 옥천사 ④ 문수암 ⑤ 거류산 ⑥ 갈모봉 ⑦ 송학동 ⑧ 장산숲 ⑨ 남산공원)
  순서를 바꾸고 싶으면 배열 순서만 바꾸면 핀 번호가 따라갑니다.
- 첫 화면에 열릴 장소는 파일 맨 아래 `window.DEFAULT_PLACE`. (지금은 거류산 = 5번)

### 숙소 (홈페이지마다 이것만 바꾸면 됨)
```js
window.STAY = { name: "숙소 위치", address: "경남 고성군 대가면 ○○길 00", x: 53.9, y: 46.3 };
```
포트폴리오용 가상 숙소이고 핀은 대가면에 있습니다.
실제 숙소로 바꿀 때 `name` 과 `x, y` 만 고치면 됩니다.
`address` 는 지금 화면에 표시되지 않는 메모용 값입니다.

### 핀 위치 잡기 — `좌표찍기.html`

더블클릭해서 열면 됩니다.

- 지도를 **클릭** → 그 지점의 `x: 00.0, y: 00.0` 이 바로 복사됨
- 기존 핀을 **끌어서** 옮기면 목록 숫자가 같이 바뀜 (바뀐 핀은 파란 링 표시)
- 숫자를 직접 입력해도 됨 (0.1 단위)
- **「places.js 전체 만들어서 복사」** → 나온 내용을 `places.js` 에 통째로 덮어쓰기
- 휠 확대 8배 · 격자 · 이름 끄기 · 원래대로

`basemap.js` 에서 지도를 읽으므로 **지도를 바꿔도 도구가 그대로 따라옵니다.**

### 지도를 바꾸고 싶을 때

**같은 크기(1448 x 1086)면 `images/map-goseong.jpg` 만 갈아끼우면 끝입니다.**

크기가 다른 그림을 쓰려면 네 군데를 그림의 픽셀 크기로 같이 맞춰야 합니다.
**하나라도 빠뜨리면 지도는 멀쩡해 보이는데 핀만 어긋납니다.**

| 파일 | 값 |
|---|---|
| `basemap.js` | `viewBox="0 0 1448 1086"` 와 `<image width height>` |
| `index.html` | `.map-wrap { aspect-ratio: 1448/1086 }` |
| `index.html` | `.link-layer` 의 `viewBox` |
| `index.html` 스크립트 | `var VB_W = 1448, VB_H = 1086;` |

그리고 **그림이 바뀌면 핀 좌표도 다시 맞춰야 합니다.** 같은 지형이라도 AI 가 다시 그리면
육지 크기·위치가 조금씩 달라져서, 이전 좌표를 그대로 쓰면 핀이 바다에 찍힙니다.
→ `좌표찍기.html` 에서 핀을 끌어 맞추면 됩니다.

> 해상도는 가로 1448px 입니다. 지도를 3.2배까지 확대할 수 있어서 최대 확대 시 약간 흐려집니다.
> 또렷하게 하려면 같은 그림을 **가로 2400px 이상**으로 다시 뽑아 교체하세요.

### 폰트 · 모션

- **폰트는 Pretendard.** `fonts/` 안의 woff2 를 `@font-face` 로 직접 물립니다.
  **외부 요청이 없어서** 아임웹처럼 외부 접속이 막히는 환경에서도 그대로 뜹니다.
  (웨이트는 400 / 600 / 700 세 종류만 들어 있습니다)
- 모션은 전부 `transform` 과 `opacity` 로만 돕니다 — 레이아웃을 다시 계산하지 않아 모바일에서도 안 버벅입니다.
  - 핀: 처음 뜰 때 순서대로 올라옴
  - 카드: 장소를 바꾸면 사진 → 본문 순으로 살짝 떠오르며 교체
  - 사진: 뜨기 전까지 스켈레톤이 흐름
- **`prefers-reduced-motion` 을 켠 사용자에게는 애니메이션이 전부 꺼집니다.**
  (운영체제 설정 · 멀미나 어지럼증이 있는 분들을 위한 접근성 설정)

### 색

- 지도 배경은 이미지라 색이 고정입니다. 지명 글자색은 `basemap.js` 안 `fill="#FFFFFF"`.
- UI 색은 `index.html` 맨 위 `:root` 에 모여 있습니다.
  - 관광지 핀 `--orange: #FF6B35` / 선택 `--orange-deep: #E8481F`
  - 숙소 핀 · CTA 버튼 `--stay: #1F3A2E` ← **숙소 브랜드 색으로 바꾸면 섹션 전체 톤이 맞습니다**

## 사진 저작권

전부 한국관광공사 사진이고 **공공누리 제1유형·제3유형이 섞여 있습니다.**
3유형은 **변형(자르기 포함) 금지**라서, 카드 사진을 `object-fit: contain` 으로 넣어
**어떤 사진도 잘리지 않게** 했습니다. 3:2가 아닌 사진(당항포 16:9, 엄홍길·갈모봉 4:3)은
위아래에 여백이 생깁니다. 이건 의도된 처리이니 `cover` 로 바꾸지 마세요.

출처는 사진 오른쪽 아래 + 섹션 맨 아래에 표기됩니다.

| 장소 | 유형 |
|---|---|
| 당항포관광지, 송학동고분군, 남산공원 | 제1유형 (출처표시 / 상업·변형 가능) |
| 상족암, 옥천사, 문수암, 거류산, 엄홍길전시관, 갈모봉, 장산숲 | 제3유형 (출처표시 / 변형 금지) |

## 확인이 필요한 것 (다음 작업)

1. **거리 수치** — 숙소(대가면)를 기준으로 보면 몇 개가 서로 안 맞습니다.
   특히 송학동고분군 6.3km / 남산공원 5km / 장산숲 14km. 네이버 지도에서 다시 재보세요.
2. **운영·주차·요금** — 지금은 비워둠. `places.js` 에 값을 넣으면 카드에 줄이 생깁니다.

> ①번 장소 이름은 해결됐습니다. 사진은 바닷가 공룡 테마 단지 항공사진이고,
> 고성 관광안내도에도 같은 자리에 「경남고성공룡세계엑스포 주행사장」이 적혀 있어
> `당항포관광지 (공룡세계엑스포)` 가 맞습니다. 원본 파일명 `고성공룡박물관.jpg` 가
> 헷갈리게 붙어 있었을 뿐입니다.

## 핀 좌표는 어떻게 맞췄나

1. 네이버 지도 스크린샷에서 고성군 경계를 픽셀 단위로 추출 → 실제 폴리곤
2. 고성 관광안내도(9곳이 표시된 원본)와 네이버 지도의 공통 지점 19곳(면 이름·IC·산)을
   짝지어 2차 다항식으로 좌표 변환
3. 네이버 지도에 이름이 직접 찍혀 있는 3곳(상족암·옥천사·당항포)은 그 라벨 위치로 보정

4. 지금의 AI 배경 지도는 위 ①의 실제 지형을 참고 이미지로 넣어 만든 것이라,
   실제 해안선과 겹쳐보면 거의 일치합니다. 그래서 좌표를 그대로 옮겨 쓸 수 있었습니다.

오차는 대략 ±1km 수준입니다. 안내용 지도로는 충분하지만,
더 정확히 맞추고 싶으면 `좌표찍기.html` 에서 핀을 끌어 미세조정하세요.

## 홈페이지에 넣을 때

- **직접 제작(Vercel 등)**: `<section>` 통째로 붙여넣고 `<style>`·`<script>` 를
  페이지에 합치면 됩니다. `basemap.js`·`places.js` 도 같이 올리세요. iframe 필요 없음.
- **아임웹**: 코드 위젯 직접 삽입 / iframe 두 가지 다 **실제 페이지에서 테스트** 필요.
  (커스텀 위젯 환경에서는 외부 요청·iframe이 제한될 수 있음)
- 모바일 실기기에서 **스크롤 충돌**(지도 위에서 페이지가 안 내려가는 현상)을 꼭 확인하세요.
  지금은 지도 영역에서만 드래그가 걸리게 해뒀습니다.
